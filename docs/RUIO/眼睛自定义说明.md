# RUIO 眼睛显示自定义说明

## 1. 概述

RUIO-S3CAM-4G 板子支持两种眼睛渲染模式，可在 `idf.py menuconfig` 中切换：

### 模式 A：LVGL 矢量猫眼 (`RUIO_EYE_VECTOR`)
- 纯 LVGL 矢量绘制的卡通猫咪风格眼睛
- 资源占用极低（无位图数据）
- 支持单眼/双眼模式
- 修改参数即可自定义

### 模式 B：像素位图写实眼 (`RUIO_EYE_BITMAP`) ← 默认
- 像素级 5 层位图合成写实眼球（移植自 RoPet 项目）
- 渲染层次：巩膜 → 虹膜(极坐标查表) → 上/下眼睑遮罩
- 默认为双屏并联单眼模式（两块屏显示相同内容）
- 通过 `eye_data_generator.py` 工具从 PNG 图片生成自定义眼睛

| 特性 | 矢量猫眼 | 位图写实眼 |
|------|----------|-----------|
| 渲染方式 | LVGL 矢量对象 | 像素级位图合成 |
| 资源占用 | 极低（无位图） | ~500KB(240) / ~228KB(160) |
| 自定义难度 | 改数字即可 | 需 PNG 素材 + 工具生成 |
| 风格 | 扁平卡通猫咪 | 写实逼真眼球 |
| 适合场景 | 单屏双眼 | 双屏并联 |

## 2. Kconfig 开关

在 `idf.py menuconfig` → "VIBRATALKIE_CONFIG" 菜单中：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `RUIO_ANIMATED_FACE` | `y` | 启用动态眼睛（关闭则显示标准emoji） |
| `RUIO_EYE_VECTOR` | | 矢量猫眼模式 |
| `RUIO_EYE_BITMAP` | `y` | 位图写实眼模式（默认） |
| `RUIO_SINGLE_EYE` | `n` | 仅矢量模式：单眼（每屏一只大眼） |

## 3. 表情参数表 (`kExpressionTable`)

这是眼睛最核心的自定义区域，位于 `vibratalkie_eye_display.cc` 顶部。

### 参数结构 `EyeParams`

```c
struct EyeParams {
    float lw, lh;    // 左眼宽高缩放（1.0 = 标准尺寸）
    float rw, rh;    // 右眼宽高缩放
    float lpdx, lpdy; // 左瞳孔偏移（-1.0 ~ 1.0，0=居中）
    float rpdx, rpdy; // 右瞳孔偏移
};
```

### 各字段含义

| 字段 | 范围 | 效果 |
|------|------|------|
| `lw` / `rw` | 0.5 ~ 1.5 | 眼球宽度缩放。>1 变宽，<1 变窄 |
| `lh` / `rh` | 0.06 ~ 1.5 | 眼球高度缩放。0.06 = 几乎闭眼，1.0 = 圆眼，>1 = 瞪大 |
| `lpdx` / `rpdx` | -1.0 ~ 1.0 | 瞳孔水平偏移。负=看左，正=看右 |
| `lpdy` / `rpdy` | -1.0 ~ 1.0 | 瞳孔垂直偏移。负=看上，正=看下 |

### 表情设计技巧

| 情绪类型 | 设计要领 |
|----------|----------|
| **开心/眯眼** | 降低 `lh`/`rh` 到 0.25~0.45，可略增 `lw`/`rw` |
| **悲伤** | 降低高度到 0.7~0.8，瞳孔向下偏移 (`lpdy`/`rpdy` = 0.3~0.4) |
| **惊讶** | 增大宽高到 1.2~1.35（瞪大眼睛） |
| **思考** | 左右眼不对称（如左眼小右眼大），瞳孔偏向一侧 |
| **困倦** | 高度极低 0.10~0.15（几乎闭合） |
| **眨眼/调皮** | 一只眼 `lh`=0.06（闭合），另一只正常 |

### 添加新表情

在表情数组中添加一条即可：

```c
{"my_emotion", {1.0f, 0.80f, 1.0f, 0.80f, 0.0f, 0.1f, 0.0f, 0.1f}},
```

表情名称需与服务端发送的 emotion 字符串匹配。未匹配的表情会回落到 neutral 默认值。

## 4. 颜色自定义

位于 `CreateFace()` 方法中：

```c
lv_color_t eye_color      = lv_color_hex(0xF0F0F0);  // 眼球（近白）
lv_color_t outline_color   = lv_color_hex(0x3A3A3A);  // 轮廓（深灰）
lv_color_t pupil_color     = lv_color_hex(0x111111);  // 瞳孔（近黑）
lv_color_t highlight_color = lv_color_hex(0xFAFAFA);  // 高光（柔白）
```

屏幕背景独立设置：
```c
lv_obj_set_style_bg_color(screen, lv_color_black(), 0);  // 黑色背景
```

**修改建议**：
- 蓝色冷调眼球：`eye_color = lv_color_hex(0xD0E8F0)`
- 暖色琥珀瞳孔：`pupil_color = lv_color_hex(0x8B4513)`
- 白色背景模式：背景改 `lv_color_white()`，轮廓改更浅色

## 5. 尺寸比例自定义

位于构造函数 `VibratalkieEyeDisplay()`：

### 双眼模式（默认，单屏显示两只眼）

```c
eye_w_   = ds * 38 / 100;   // 眼球宽 = 屏幕短边 38%
eye_h_   = ds * 40 / 100;   // 眼球高 = 屏幕短边 40%
pupil_w_ = ds * 14 / 100;   // 瞳孔宽（竖瞳窄）
pupil_h_ = ds * 28 / 100;   // 瞳孔高（竖瞳长）
eye_gap_ = ds * 10 / 100;   // 两眼间距
```

### 单眼模式（每屏一只大眼）

```c
eye_w_   = ds * 75 / 100;   // 眼球占屏 75%
eye_h_   = ds * 78 / 100;
pupil_w_ = ds * 22 / 100;
pupil_h_ = ds * 45 / 100;
eye_gap_ = 0;
```

`ds = min(width, height)` 是屏幕短边像素值（如 240px 的圆屏，ds=240）。

### 调整建议

| 想要效果 | 调整方法 |
|----------|----------|
| 更大的眼睛 | 增大 `eye_w_`/`eye_h_` 比例 |
| 更圆的瞳孔 | 让 `pupil_w_` 接近 `pupil_h_` |
| 更细的竖瞳 | 减小 `pupil_w_`，增大 `pupil_h_` |
| 眼睛靠近 | 减小 `eye_gap_` 比例 |

## 6. 动画时间参数

### 眨眼

| 参数 | 位置 | 默认值 | 说明 |
|------|------|--------|------|
| 快速闭眼 | `DoBlink()` | 100ms | 闭合持续时间 |
| 快速睁眼 | `OnBlinkCloseDone()` | 150ms | 睁开持续时间 |
| 慢闭眼 | `DoSlowBlink()` | 300ms | 猫咪信任慢眨眼闭合 |
| 慢睁眼 | `OnSlowBlinkCloseDone()` | 400ms | 猫咪信任慢眨眼睁开 |
| 眨眼间隔 | `BlinkTimerCb()` | 2~5秒随机 | `2000 + random(3000)` |
| 慢眨眼频率 | `BlinkTimerCb()` | 每3~5次快眨后1次 | `3 + random(3)` |

### 瞳孔漂移

| 参数 | 位置 | 默认值 | 说明 |
|------|------|--------|------|
| 漂移间隔 | `PupilDriftCb()` | 1.5~4秒 | `1500 + random(2500)` |
| 平滑动画 | `PupilDriftCb()` | 400~700ms | `400 + random(300)` |
| 漂移范围 | `PupilDriftCb()` | 瞳孔宽度 | `range = pupil_w_` |
| 两眼微差 | `PupilDriftCb()` | ±1px | 让两眼不完全同步 |

### 消息浮层

| 参数 | 位置 | 默认值 | 说明 |
|------|------|--------|------|
| 显示时长 | `#define MESSAGE_DISPLAY_MS` | 3000ms | 文字消息自动消失时间 |

## 7. 高光点

高光点模拟光线反射效果，位于分析计算在 `UpdateHighlights()`：

```c
hl_size_ = max(pupil_w_ / 2, 4);  // 高光尺寸 = 瞳孔宽度一半（最小4px）
```

- **基础偏置**: 右上方（`pupil_w_/3`, `-pupil_h_/4`）
- **跟随比例**: 瞳孔移动量的 30%
- **范围限制**: 不超出眼球边界

## 9. 位图写实眼 (RUIO_EYE_BITMAP) 详细说明

### 9.1 渲染原理

眼球通过 5 层位图合成渲染，直接用 `esp_lcd_panel_draw_bitmap()` 写入 LCD（绕过 LVGL）：

1. **巩膜 (sclera)** - RGB565 彩色背景（白眼球），尺寸大于屏幕
2. **虹膜 (iris)** - RGB565 极坐标展开图，通过 polar 查表映射到圆形
3. **极坐标 (polar)** - uint16 查表，将虹膜圆盘映射到屏幕坐标
4. **上眼睑 (upper)** - uint8 亮度遮罩，低于阈值的像素变黑
5. **下眼睑 (lower)** - uint8 亮度遮罩，同上

逐像素判断顺序：眼睑遮挡 → 虹膜区域(极坐标查表) → 巩膜

### 9.2 动画系统

- **眼球运动**: 缓动曲线(ease)平滑插值到目标位置
- **眨眼**: 随机间隔触发，通过调节眼睑阈值实现闭合/睁开
- **虹膜缩放**: 递归分裂(Split)模拟瞳孔对光线的反应
- **表情控制**: `SetEmotion()` 设置眼球目标位置(0-1023坐标系)

### 9.3 表情→眼球位置映射

在 `vibratalkie_bitmap_eye_display.cc` 的 `kEmotionTable[]`：

| 表情 | X | Y | 眨眼 | 跟踪 | 效果 |
|------|---|---|------|------|------|
| neutral | 512 | 512 | ✓ | ✓ | 正视前方 |
| happy | 512 | 400 | ✓ | ✓ | 略微上看 |
| sad | 512 | 650 | ✓ | ✓ | 向下看 |
| angry | 512 | 550 | ✗ | ✓ | 瞪视 |
| surprised | 512 | 300 | ✓ | ✓ | 上看（惊讶） |
| thinking | 700 | 350 | ✓ | ✓ | 看右上 |
| sleepy | 512 | 600 | ✓ | ✗ | 下垂 |

坐标 (512,512) = 正中心，0 = 最左/上，1023 = 最右/下

### 9.4 自定义眼睛素材

#### 所需 PNG 文件

| 文件 | 类型 | 240屏尺寸 | 160屏尺寸 | 说明 |
|------|------|-----------|-----------|------|
| sclera.png | RGB 彩色 | 375×375 | 250×250 | 白眼球背景，比屏幕大以允许眼球移动 |
| iris.png | RGB 彩色 | 471×75 | 314×50 | 虹膜极坐标展开图（横轴=角度，纵轴=半径） |
| upper.png | 灰度 | 240×240 | 160×160 | 上眼睑遮罩，黑色=遮挡，白色=透明 |
| lower.png | 灰度 | 240×240 | 160×160 | 下眼睑遮罩，同上 |
| polar.png | 可选 | 150×150 | 100×100 | 极坐标查表，通常由工具自动生成 |

#### 使用生成工具

```bash
# GUI 模式
python3 docs/RUIO/eye_data_generator.py

# CLI 模式
python3 docs/RUIO/eye_data_generator.py --cli \
    --sclera my_sclera.png \
    --iris my_iris.png \
    --upper my_upper.png \
    --lower my_lower.png \
    --screen 240 \
    --output main/boards/vibratalkie/eye_data/240/
```

#### 替换步骤

1. 准备 PNG 素材（参照上表尺寸）
2. 运行 `eye_data_generator.py` 生成 `.h` 文件
3. 将生成的文件复制到 `main/boards/vibratalkie/eye_data/240/`（或 `160/`）
4. 重新编译: `idf.py build flash`

### 9.5 Flash 占用

| 配置 | 数据量 | 说明 |
|------|--------|------|
| 1 个样式 (240×240) | ~500KB | 默认配置 |
| 1 个样式 (160×160) | ~228KB | GC9D01 小屏 |

当前 app 分区 4MB，固件约 3.4MB（含 1 个眼球样式），剩余约 640KB。

### 9.6 眼睛素材制作技巧

**巩膜 (sclera)**:
- 在图像编辑器中创建比屏幕大的圆形白色渐变球体
- 可添加血丝纹理（如 RoPet 的 blood 样式）
- 边缘渐变为深色可增强立体感

**虹膜 (iris)**:
- 需要做极坐标展开：横轴 = 0°~360° 角度，纵轴 = 中心到边缘的半径
- 可以在 Photoshop/GIMP 中使用极坐标滤镜从圆形虹膜图片生成
- 颜色从中心(瞳孔,深色)到边缘(虹膜纹理)变化

**眼睑 (upper/lower)**:
- 灰度图，值 0(黑) = 遮挡，值 255(白) = 完全透明
- 模拟真实眼睑形状，上睑覆盖上方更多
- 上下眼睑分开绘制，支持不对称睁闭

## 10. 快速自定义流程

1. **预览效果**：运行 `docs/RUIO/eye_preview_tool.py` 可视化调参
2. **修改参数**：编辑 `main/boards/vibratalkie/vibratalkie_eye_display.cc`
3. **编译烧录**：`idf.py build flash`
4. **测试表情**：通过服务端发送不同 emotion 字符串验证
